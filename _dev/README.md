# Developer reference pages

These HTML files are internal reference, not public pages. They are not linked from
the site navigation and are not deployed.

- **design-system.html** — visual catalogue of every component, token and pattern in `css/site.css`.
  Open it in a browser to see the design system at a glance.
- **motion.html** — animation and scroll-driven motion studies that informed the decisions
  in `js/site.js`. Reference only.

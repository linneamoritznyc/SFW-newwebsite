Key components

Band
.band, .stratum

Full-width horizontal section. Variants: --deep (dark ground), --moss (green), --cream.

Card
.card, .cards

Flex column with hairline top border. Inside .cards grid: gets padding, white background, shadow, rounded corners.

Chip
.chip, .chips

Filter pill. Toggles with aria-pressed. Used on research, community, volunteer pages.

Eyebrow
.eyebrow

Small uppercase label above a heading. Montserrat 600, letter-spaced, usually in Green or Sage.

Lede
.lede

Opening paragraph in Montserrat at --t2 size. Sets the tone for a section.

Panel
.panel

Cream rectangle behind grouped content. A shape, never the page background.

Shot / Plate
.shot, .plate

Photograph containers. Rise-in animation on scroll (skipped for reduced motion).

Accordion
[data-accordion]

One section open at a time. Used in overlay menu and Learn page.

Video facade
[data-film], [data-theatre]

Poster + play button. Nothing loads from Vimeo until clicked.

Rack
.rack

Scroll-driven video scrub. The organism moves when the reader moves.

Before / After
[data-compare]

Two photographs with a draggable split. Range input for keyboard access.

Pathway diagram
[data-pathway]

Interactive course map on the Learn page. Hover or tap to explore paths.

Rules

RuleDetail
One shadowThe whole site uses one shadow value. Nothing else casts.
Cream is a shapeOrganic Cream (#F4F1EA) is only used as a bounded rectangle, never as the page background.
Legacy Purple is restricted#6B4C7A appears only on Dr. Elaine Ingham content.
Green Legacy is decorative#59A66C fails contrast. Never use it for text.
Harvest Gold is for Donate#C9A227 appears only on the donate button.
No animation libraryAll motion is vanilla JS + CSS transitions. Reduced motion is always respected.
Self-hosted fontsNo external font service. All fonts are WOFF2 in /fonts/.
One stylesheet, one scriptcss/site.css and js/site.js. No others.

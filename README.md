# Soil Food Web Foundation — site build

Static HTML, one stylesheet (`css/site.css`), one script (`js/site.js`), self-hosted fonts.
Open `design-system.html` in a browser. No build step.

Stage 1 (7 Sep 2026): design system, header, overlay menu, footer.
Tokens live in `:root` at the top of `site.css`. Icons are inline SVG symbols
(`img/icons.svg`, also inlined in each page for file:// viewing).

Fonts: EB Garamond and Source Sans 3, SIL Open Font License (licences in `fonts/`).
